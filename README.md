# tangnano20k-open-source-workflow
Open-source toolchains template for sipeed tang nano 20k (GW2AR-18C)

# Usage
``` bash
just

Available recipes:
    bitstream-generate   # Bitsteam [aliases: b, bit, bitstream, fs]
    clean
    default              # Miscs
    detect               # [alias: d]
    load-permanent
    load-sram            # Flashing [aliases: fl, flash, l, load, sram]
    netlistsvg [OPTIONS]
    place-and-route      # [aliases: p, pnr]
    place-and-route-gui  # [aliases: graphic, gui, pnr-gui]
    place-and-route-svg  # [alias: pnr-svg]
    svg [OPTIONS]
    synthesis            # [aliases: s, synth]
    yosys-svg [OPTIONS]
```
